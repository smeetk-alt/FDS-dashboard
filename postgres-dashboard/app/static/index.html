How it is built

From raw CSV to this page, in SQL

CSV 768,600 rows→ COPY into stg_raw→ 02_clean_transform.sql cleans and converts→ star schema fact_weather + dim_cell + dim_district→ materialized views + indexes→ one .sql file per panel→ charts

Every panel below runs a real query against PostgreSQL. Open Show SQL under any panel to read the exact statement and how long it took, or use the SQL console at the bottom to write your own.

    Hypothesis testing

    Is the difference real?

    vs

    Welch’s t-test on daily means for the selected variable and district. SQL computes the sufficient statistics, t, degrees of freedom and Cohen’s d; the p-value uses the t distribution, which PostgreSQL does not have, so Python adds it.
